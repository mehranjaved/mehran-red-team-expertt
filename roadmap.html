LEARNING PLAN

Cybersecurity Roadmap

A foundation-first progression. Move forward when you can explain and apply the current stage—not just recognize tool names.

01

Computer fundamentals

Hardware, CPU, RAM, storage, operating systems, filesystems, processes, users, permissions and command-line basics.

02

Networking foundations

IPv4/IPv6, private/public addressing, subnetting, MAC, ARP, DNS, DHCP, TCP/UDP, ports, routing, HTTP/HTTPS and TLS.

03

Linux and Windows administration

Terminal/PowerShell, users, groups, services, processes, logs, permissions, networking commands, updates and troubleshooting.

04

Programming and scripting

Python fundamentals, shell scripting, PowerShell, Git, JSON, regular expressions and reading code safely.

05

Security fundamentals

CIA triad, threat modelling, authentication, authorization, cryptography concepts, vulnerability management and risk.

06

Web technologies

HTML, CSS, JavaScript basics, HTTP requests/responses, cookies, sessions, APIs, databases and browser security model.

07

Web security in authorized labs

Input validation, access control, authentication, injection concepts, request handling, file handling and secure remediation.

08

Assessment workflow and reporting

Define scope, gather permitted evidence, validate safely, assess impact, write clear reports and retest fixes.

09

Advanced topics—after foundations

Active Directory concepts, cloud security, containers, mobile security, detection engineering and purple-team collaboration.

This roadmap is educational, not a promise of job readiness. Professional capability requires sustained practice, feedback, sound judgement and verified experience.
